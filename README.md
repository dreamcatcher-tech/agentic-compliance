# Agentic Compliance

[Open the interactive service preview](https://dreamcatcher-tech.github.io/agentic-compliance/).

A self-contained, informational static preview of a proposed evidence and readiness service. Scope and prices are proposed; evidence records and contract downloads are illustrative. No customer systems are connected, and there are no live assessment, booking, order or payment endpoints. This preview makes no claim of accreditation, staff credentials or operational service readiness.

GitHub Pages publishes `docs/` from `main`. The page uses inline CSS and JavaScript, with no external assets or analytics. `docs/.nojekyll` enables no-build static publication. The robots metadata is a crawler hint, not access control; this repository and site are public.
